Locator thresholding: global and patch

These existing regression fixtures add a white border to UPC and EAN photos. Compare the actual locator binary image and the boxes it passes to the decoder. The decoder samples the grayscale image separately in both modes.

Build with npm run build:dev and serve the repository root to use this page.

Binary images use white for the dark class (bars). Blue outlines are candidate boxes; green lines produced the expected value, red lines produced another value. Correct and incorrect values may coexist. This is a diagnostic example, not a timing benchmark.
